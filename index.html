게임 방법

🎯 목표

차례대로 포탄을 던져 상대를 쓰러뜨리세요. 마지막까지 살아남은 사람이 승리! 섬 아래 빈 공간으로 떨어지면 즉시 탈락이에요.

🔄 내 차례

한 턴은 30초. 이동 → 조준 → 발사 순서로 진행해요. 이동은 아래쪽 초록 연료 만큼만 할 수 있어요. 발사하면 턴이 끝나요.

📱 조작 (모바일)

◀ ▶ 이동 · 발사 버튼 위 점프 (공중에서도 ◀ ▶ 로 방향 조절) · 화면 위아래 드래그 = 각도 · 발사 버튼을 누르고 있다가 떼기 = 파워 · 두 손가락 = 화면 이동/확대 · 미니맵 터치 = 그곳 보기

⌨️ 조작 (PC)

←→ 이동 · ↑↓ 또는 마우스 드래그 = 각도 · 스페이스 = 파워 · W = 점프 · 1/2/3 = 스킬1/스킬2/궁극기 · 우클릭 드래그 = 화면 이동 · 휠 = 확대

🌬️ 바람

위쪽 바람 표시의 화살표 방향으로 포탄이 밀려요. 턴마다 바뀌고 조금씩 출렁여요. 숫자가 클수록 세요.

🎯 조준 도우미

내 차례에는 지난번 궤적이 흰 점선으로, 지난번 파워가 게이지 위 흰 삼각형으로 보여요. 보고 조절하세요!

💧 마나 & 스킬

파란 줄이 마나. 시간이 지나면 조금씩 차고 상대를 맞히면 더 차요. 스킬 버튼을 누르면 마나를 써서 다음 발사에 적용 (다시 누르면 취소). 한 턴에 하나만. 버튼을 길게 누르면 설명.

💜 궁극기

기본 공격으로 상대를 2번 맞히면 해금(목록에 ★ 표시), 그다음부터 마나로 사용해요.

💥 피해

폭발 중심에 가까울수록 큰 피해, 직접 맞히면 보너스. 맞으면 살짝 밀려나요. 높은 곳에서 떨어지면 낙하 피해가 있어요. 폭발하면 땅이 파여요.

🗺️ 맵 규칙

도시/야경 도시: 기본 · 화성: 중력 약함 · 설원: 바람 강함 · 정글: 바람 약함 · 사막/화산: 구멍이 크게 파임 · 우주: 중력 약함, 바람 없음. 경기 시작 때 안내가 떠요.

🎲 랜덤 & 히든

캐릭터를 랜덤으로 고르면 낮은 확률로 히든 캐릭터가 나와요!

💬 채팅

온라인 게임 중 💬 버튼으로 채팅. 말하면 머리 위 말풍선 + 왼쪽 채팅 목록에 떠요. 화면 밖 사람이 말하면 화면 가장자리에 말풍선이 붙어요.

📝 피드백 · 버그 신고

온라인 로비나 대기실의 📝 피드백 버튼으로 밸런스 의견이나 버그를 보내 주세요. 제작자가 직접 읽어요!
